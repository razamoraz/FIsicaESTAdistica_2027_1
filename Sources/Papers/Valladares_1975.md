# The Debye model in n dimensions (Valladares, 1975)

## 📌 Resumen
Generaliza el modelo de Debye para vibraciones de red (fonones) a un espacio de $n$ dimensiones espaciales arbitrarias, deduciendo la densidad de estados vibracionales $g(\omega) \propto \omega^{n-1}$ y demostrando que la capacidad térmica a bajas temperaturas escala como $C_V \propto T^n$.
