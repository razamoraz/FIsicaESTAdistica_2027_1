# On solving the Ising model functional relation without elliptic functions (Baxter, 1991)

## 📌 Resumen
El célebre físico matemático Rodney J. Baxter demuestra cómo resolver las relaciones funcionales de la energía libre del modelo de Ising bidimensional de forma simplificada, eludiendo la compleja maquinaria de integrales elípticas de Onsager mediante propiedades de conmutación de matrices de transferencia.
