# 💻 Laboratorios Computacionales y Notebooks

Esta carpeta contiene los materiales y ejemplos en **Python** y **Julia** para las prácticas numéricas del curso, diseñados para ejecutarse en **Google Colab** o en entornos locales (Jupyter / Pluto.jl).

---

## 📁 Estructura

- `Notebooks/Python/`: Cuadernos Jupyter (`.ipynb`) utilizando NumPy, SciPy y Matplotlib:
  - `01_Statistical_Physics_Basics.ipynb`: Introducción a distribuciones estadísticas (Maxwell-Boltzmann) y Monte Carlo.
  - `02_Camino_Aleatorio_1D_Reif.ipynb`: Camino aleatorio 1D, combinatoria binomial, cálculo de momentos y aproximación gaussiana para $N \gg 1$ (Reif Cap. 1, Secs. 1.2–1.5).
- `Notebooks/Julia/`: Cuadernos `.ipynb` / scripts utilizando Julia para simulaciones de alta velocidad, física estadística computacional y modelos de red (Lattice Boltzmann).

---

## 🚀 Cómo ejecutar en Google Colab

Puedes abrir cualquiera de los cuadernos directamente en Google Colab añadiendo el prefijo de GitHub a la URL o cargando el archivo `.ipynb`.
